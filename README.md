# Rabin Fire Engineering Suite

Professional Persian RTL fire-engineering calculation platform for Rabin Azar Vira.

- React + TypeScript + Vite
- Supabase Auth / Postgres / RLS / Edge Functions
- Vercel deployment target: https://engin.rabinazar.ir
- Calculation engine: Supabase Edge Function calculate v0.3.0

The application is an engineering aid. Final design remains subject to adopted standards, AHJ requirements, manufacturer data, project conditions and qualified review.
