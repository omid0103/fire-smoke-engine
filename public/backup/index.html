معرفیحریم خصوصیشرایط استفاده

پشتیبان‌گیری سامانه مهندسی رابین

Rabin Engineering Backup ابزار مدیریتی رابین آذر ویرا برای تهیه و نگهداری نسخه رمزگذاری‌شده پایگاه داده سامانه محاسبات مهندسی حریق است. استفاده از آن مختص مدیران مجاز سامانه است؛ کاربران محاسبات برای استفاده از نرم‌افزار نیازی به اتصال حساب گوگل خود ندارند.

این صفحه معرفی ابزار است و به معنی فعال بودن پشتیبان‌گیری نیست. بهره‌برداری به تکمیل اتصال، اجرای موفق و آزمون بازیابی وابسته است.

نحوه کار

پس از راه‌اندازی، فرایند پشتیبان‌گیری در GitHub Actions اجرا می‌شود، خروجی پایگاه داده را رمزگذاری می‌کند و فایل رمزگذاری‌شده را در پوشه خصوصی حساب Google Drive مدیر قرار می‌دهد. فایل بارگذاری‌شده برای بررسی صحت انتقال دوباره دریافت و چک می‌شود.

دسترسی به گوگل‌درایو

ابزار مجوز محدود https://www.googleapis.com/auth/drive.file را درخواست می‌کند تا فایل‌ها و پوشه‌های ساخته‌شده یا صریحاً در اختیار برنامه قرارگرفته را مدیریت کند. ابزار برای خواندن سایر فایل‌های شخصی، Gmail یا مخاطبان طراحی نشده است.

جزئیات استفاده از داده‌ها در سیاست حریم خصوصی و الزامات بهره‌برداری در شرایط استفاده آمده است.

About this application

Rabin Engineering Backup is an administrator-operated utility by Rabin Azar Vira for encrypted database backups of its fire engineering application. It uses Google Drive's drive.file permission to create a private backup folder, upload encrypted archives, download them to verify integrity, and manage retention. It is not a public Google sign-in service. Setup and a verified restoration drill are required before operational use.
