سیاست حریم خصوصی پشتیبان‌گیری

این سیاست فقط ابزار Rabin Engineering Backup و اتصال مدیریتی آن به Google Drive را پوشش می‌دهد.

داده‌های مورد استفاده

ابزار از توکن مجوز گوگل برای دسترسی محدود به فایل‌های برنامه استفاده می‌کند. داده‌های Google Drive مورد پردازش شامل شناسه و نام فایل و پوشه، زمان ایجاد، ویژگی‌های اختصاصی فایل، وضعیت اشتراک‌گذاری پوشه و محتوای رمزگذاری‌شده نسخه پشتیبان است. خواندن محتوای رمزگذاری‌شده برای مقایسه صحت انتقال انجام می‌شود.

نسخه پشتیبان پایگاه داده ممکن است شامل اطلاعات حساب کاربران، پروژه‌ها، گزارش‌های محاسبات و سوابق اشتراک باشد. این داده‌ها از پایگاه داده سامانه می‌آیند و پیش از بارگذاری در Google Drive با کلید عمومی رمزگذاری می‌شوند.

هدف، دسترسی و ارائه‌دهندگان

استفاده از داده‌ها صرفاً برای ایجاد نسخه پشتیبان، بررسی صحت، نگهداری و بازیابی مجاز است. Google Drive فایل رمزگذاری‌شده و فراداده آن را نگهداری می‌کند. GitHub Actions خروجی خام پایگاه داده را موقتاً برای رمزگذاری پردازش می‌کند. اعتبارنامه‌ها باید در بخش Secrets تنظیم شوند و نباید در مخزن عمومی، گزارش اجرا یا پیام قرار گیرند. کلید خصوصی بازیابی باید جداگانه نزد مالک نگهداری شود.

برنامه داده‌های دریافتی از Google APIs را برای تبلیغات، فروش اطلاعات یا آموزش مدل‌های هوش مصنوعی استفاده نمی‌کند. استفاده و انتقال این داده‌ها تابع Google API Services User Data Policy، از جمله الزامات Limited Use است.

نگهداری و حذف

تا پیش از تأیید آزمون بازیابی، پاکسازی خودکار غیرفعال است. پس از فعال‌شدن سیاست نگهداری، مجموعه نسخه‌های منتخب روزانه، هفتگی و ماهانه حفظ می‌شود و نسخه‌های قدیمی متعلق به برنامه به سطل زباله Drive منتقل می‌شوند. برنامه حذف دائمی انجام نمی‌دهد؛ نگهداری و تخلیه سطل زباله تابع تنظیمات و سیاست‌های Google Drive است. فایل‌های خام موقت در پایان اجرا پاک می‌شوند؛ فراداده اجرای فرایند ممکن است طبق تنظیمات GitHub نگهداری شود.

لغو دسترسی و درخواست حذف

مالک می‌تواند اتصال برنامه را از بخش اتصال‌های شخص ثالث حساب گوگل لغو کند، اجرای پشتیبان‌گیری را متوقف کند و فایل‌های موجود را در Google Drive مدیریت یا حذف کند. لغو دسترسی به‌تنهایی فایل‌های قبلی را حذف نمی‌کند. برای پرسش یا درخواست بررسی و حذف داده با ایمیل درج‌شده در پایین صفحه تماس بگیرید؛ درخواست‌های مربوط به داده‌های دیگران نیازمند احراز مجوز هستند.

Google user data disclosure

We use drive.file authorization only for backup-related files created by or explicitly made available to this app. We process file identifiers, names, timestamps, app properties, folder permissions and encrypted archive bytes for backup storage, integrity verification and retention. Google stores encrypted archives; GitHub Actions temporarily processes database exports before encryption. We do not sell Google user data, use it for advertising, or train AI models with it. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including Limited Use requirements. Revoking authorization stops future access but does not remove existing backups. Contact the operator below for privacy requests.
